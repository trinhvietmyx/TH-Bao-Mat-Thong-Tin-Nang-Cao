- `ex03_04.py`: Truy cập phần tử trong tuple.

### 3. Lập trình hướng đối tượng (`ex04`)
Xây dựng chương trình quản lý sinh viên hoàn chỉnh với các tính năng:
- **Thêm sinh viên**: Nhập thông tin và tự động xếp loại học lực.
- **Cập nhật thông tin**: Sửa đổi thông tin sinh viên dựa trên ID.
- **Xóa sinh viên**: Loại bỏ sinh viên khỏi danh sách theo ID.
- **Tìm kiếm**: Tìm sinh viên nhanh chóng theo tên.
- **Sắp xếp**:
    - Theo điểm trung bình (GPA).
    - Theo tên (A-Z).
- **Hiển thị**: Xuất danh sách sinh viên dưới dạng bảng đẹp mắt.

**Các tệp tin:**
- `SinhVien.py`: Định nghĩa class `SinhVien`.
- `QuanLySinhVien.py`: Chứa logic xử lý danh sách.
- `Main.py`: Giao diện dòng lệnh (CLI).
